## 2024-03-26 - Replacing Prisma In-Memory Filtering with Aggregations and Promise.all
**Learning:** Using `prisma.findMany` (or `findAll` service wrappers) to fetch entire tables and then using standard JavaScript array methods (`filter`, `reduce`) in-memory creates a severe O(N) performance bottleneck and memory overhead as data grows. Specifically, in the dashboard controller, metrics were calculated sequentially using a massive loaded array.
**Action:** Replace in-memory aggregations with dedicated database-level queries (e.g., `prisma.aggregate({ _sum: ... })`, `prisma.count({ where: ... })`) to offload the work to the DB engine. Crucially, group these independent DB calls using `Promise.all` to fetch metrics concurrently, significantly reducing total response time.
