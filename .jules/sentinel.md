## 2025-04-15 - Hardcoded JWT Secret Vulnerability
**Vulnerability:** The application uses a hardcoded fallback string `'secret'` for the JWT signing key in `AuthModule` and `JwtStrategy` when `process.env.JWT_SECRET` is not set. This is a critical security vulnerability as it allows any attacker who knows this default secret to forge valid JWT tokens, bypass authentication, and access or modify sensitive data.
**Learning:** `JwtModule.register()` configures the secret synchronously at import time. Evaluating `process.env.JWT_SECRET` here often fails or causes issues if environment variables aren't loaded yet.
**Prevention:** Use `JwtModule.registerAsync()` along with `ConfigModule` and `ConfigService` to inject the configuration asynchronously. Enforce the presence of `JWT_SECRET` by throwing an error if it's missing, rather than falling back to an insecure default. For tests, checking `NODE_ENV === 'test'` to bypass the strict check is acceptable but must be explicit.
